# 🇹🇭 거지맵 태국판

태국 전 지역 극가성비 식당 정보 공유 플랫폼

## 📌 주요 기능

- 🗺️ **맛집 목록** — 카테고리 & 지역 필터
- 📍 **제보 시스템** — 익명 제보 후 어드민 승인
- ⚙️ **어드민 패널** — 맛집 관리, 승인/거절, 통계 대시보드

## 🌏 대상 지역
방콕 · 파타야 · 푸껫 · 치앙마이

## 🚀 바로 실행

```bash
# 별도 설치 없음! index.html 브라우저에서 열기
open index.html
```

## 📁 파일 구조

```
geoji-map-thailand/
└── index.html     # 메인 + 어드민 통합 단일 파일
```

## 🌐 배포 (GitHub Pages)

1. GitHub에서 이 저장소로 이동
2. **Settings** → **Pages**
3. Branch: `main` / Folder: `/ (root)` 선택 후 **Save**
4. 몇 분 후 `https://유저명.github.io/geoji-map-thailand/` 접속 가능

## 🔧 어드민 접속

우측 상단 **⚙️ 어드민** 버튼 클릭
(나중에 비밀번호 보호 추가 예정)
